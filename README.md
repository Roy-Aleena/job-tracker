# Job Tracker

Tracks job applications and job leads straight from Gmail (read-only). Installable on phone and laptop, hosted on GitHub Pages.

- Applications: status from Waiting → Assessment → Interview → Offer / Rejected
- Job leads: job alerts and recruiter emails from the last 30 days
- Date filter and an "applied today" counter

Built with plain HTML/JS, Gmail API and Google Identity Services. No server; everything runs in the browser.
